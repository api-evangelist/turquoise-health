## MCP (for AI agents)
- Endpoint: https://consumer-mcp.turquoise.health/mcp
- Transport: streamable HTTP; auth via OAuth 2.0 client-credentials bearer token (scope read:mcp)
- Interactive clients (Claude Code, Claude Desktop) can instead sign in through the browser with a Turquoise account; the server then scopes calls to that user's organization
- Tools: find_entity, compare_prices, provider_cost_detail, estimate_out_of_pocket, explain_pricing
- estimate_out_of_pocket runs a consented member eligibility check; it additionally requires the read:eligibility scope and, for real patient data, production access under a signed BAA
